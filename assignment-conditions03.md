## 🚀 Assignment Overview

You will create a single JavaScript file called **assignment2.js** and implement the tasks below.

Each task should include:

- A comment explaining what you're doing
- Variables with meaningful names
- Results printed using `console.log()`

---

## 📌 TASK 1 — Create a Simple Math Story

Write a short story using variables and operators.

Example idea (don’t copy):

> A shopkeeper had 50 mangoes. He sold 17. Then he bought 10 more…

Your version should:

- Use at least **4 variables**
- Use **at least 3 operators** (+, -, \*, /, %)
- End by printing a sentence like:  
  `"After all the events, the shopkeeper now has X mangoes."`

---

## 📌 TASK 2 — Age Category Checker

Create a variable called `age`.

Write conditions to print:

- `"You are a child"` if age is less than 13
- `"You are a teenager"` if age is 13–19
- `"You are an adult"` if age is 20–59
- `"You are a senior"` if age is 60 or above

Use **if / else if / else**.

---

## 📌 TASK 3 — Temperature Status

Create a variable `temperature`.

Write a program that prints:

- `"Cold"` if `temperature < 18`
- `"Warm"` if `temperature` is between 18 and 30
- `"Hot"` if `temperature > 30`

---

## 📌 TASK 4 — Bonus Challenge 🎉

Pick ANY real-life object or scenario (phone battery, football match, transport fare, fuel, etc.)  
Create **two variables** that represent some values.

Use **one condition** to check something about them.

Examples:

- If battery < 20 → print “Battery low!”
- If goalsA > goalsB → print “Team A is winning!”
- If fuel < 5 → print “Please refuel!”

Be creative!
